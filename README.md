# SGS Test Runner

اپ اندروید برای اجرای ۱۱۹۲ تست‌کیس فایل SGS_test.xlsx روی خود دستگاه.

## ساخت APK بدون Android Studio (GitHub Actions)
1. در github.com یک repository جدید (مثلاً private) بسازید.
2. همه فایل‌های این پوشه را (از جمله پوشه `.github`) آپلود کنید.
3. تب Actions > Build APK > Run workflow.
4. بعد از ~۵ دقیقه، از پایین صفحه‌ی همان اجرا، فایل SgsTestRunner-APK را دانلود کنید (داخلش app-debug.apk است).

## نصب روی دستگاه
APK را با فلش/ADB/مرورگر روی دستگاه ببرید و نصب کنید (نصب از منابع ناشناس را مجاز کنید).
Android 7.0 (API 24) به بالا.

## تب‌ها
- تست‌ها: چک‌لیست کامل، ثبت نتیجه/توضیحات/لاگ/کارشناس، خروجی CSV
- بررسی خودکار: سنجش Wi-Fi، بلوتوث، صدا، زمان، فلش، فونت و ثبت در یادداشت تست‌های مرتبط؛ مقایسه وضعیت قبل و بعد از ریبوت
- رویدادها: لاگ زمان‌دار Wi-Fi/بلوتوث/فلش/ریبوت/دکمه‌ها
